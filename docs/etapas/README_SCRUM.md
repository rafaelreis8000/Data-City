# Planejamento Scrum - DataCity Analytics

## 1. Objetivo

Organizar o desenvolvimento do DataCity Analytics em quatro Sprints, distribuídas ao longo de aproximadamente um mês, priorizando os requisitos obrigatórios do estudo de caso.

## 2. Planejamento das Sprints

### Sprint 1 - Planejamento e Ambiente

**Objetivo: Preparar a estrutura técnica e definir a arquitetura orientada a objetos.**

- Revisar o estudo de caso;
- Organizar os diretórios e a documentação;
- Configurar o ambiente virtual Python;
- Declarar as dependências;
- Configurar a conexão com o MongoDB;
- Definir os modelos de domínio;

### Sprint 2 - Banco e consultas

**Objetivo: validar, importar e consultar os dados.**

- Inspecionar os arquivos JSON;
- Definir o mapeamento entre os campos e as coleções;
- Implementar os repositórios;
- Importar os dados sem duplicações acidentais;
- Criar consultas e filtros;

### Sprint 3 - Preparação e Análise

**Objetivo: Transformar os documentos em dados analíticos confiáveis.**

- Converter documentos em DataFrames;
- Verificar ausências e duplicidades;
- Tratar inconsistências de forma justificada;
- Calcular indicadores;
- Responder às perguntas de investigação;

### Sprint 4 - Visualização e entrega

**Objetivo: consolidar os resultados e demonstrar a aplicação.**

- Criar pelo menos quatro gráficos;
- Interpretar os resultados;
- Formular três recomendações fundamentais nos resultados;
- Exportar as tabelas em CSV;
- Elaborar o notebook e o relatório técnico;
- Executar os testes finais;
- Preparar a apresentação;
